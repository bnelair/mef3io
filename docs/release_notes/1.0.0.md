# mef3io 1.0.0

*Released 2026-07-04*

## Highlights

- MATLAB users now download a single `mef3io-matlab-vX.Y.Z.zip` bundle from the
  GitHub release: the `+mef3io` classes plus the MEX binaries for Linux
  (x86_64), macOS (Apple silicon) and Windows (x64) in one folder to add to the
  MATLAB path. See [Installation](https://bnelair.github.io/mef3io/install/).

## Fixes

- A channel's metadata file (`.tmet`) is now checked in full when a session is
  opened. Previously only its first 1 KB was verified, so damage to fields such
  as the sampling rate or the units conversion factor went unnoticed and could
  silently mis-scale every sample. Such a file now raises a clear CRC error.

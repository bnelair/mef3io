# mef3io 0.2.0

*Released 2026-07-03*

The first tagged version of mef3io: a single C++ core for reading and writing
MEF 3.0, with Python and MATLAB bindings. This tag was never published to PyPI
(its release build failed); [0.3.0](https://bnelair.github.io/mef3io/release_notes/0.3.0/) is the first installable release
and contains everything listed here.

## Highlights

- Read and write MEF 3.0 sessions from Python, MATLAB and C++, cross-checked
  against the legacy `mef_tools`/pymef stack: sample values, gaps (NaN),
  timestamps, encryption (level 1 and 2), fractional sampling rates and
  annotations.
- Append to a recording: a later write extends the channel's last segment in
  place, across separate runs; `new_segment=True` starts a fresh segment.
- `Reader.segments(channel)` shows where data sits in each segment, without
  decoding anything.
- Drop-in for legacy code: `from mef3io import MefReader, MefWriter` runs
  existing `mef_tools` scripts with only the import changed.
- MATLAB binding (`mef3io.Reader` / `mef3io.Writer`).
- Documentation site with install guides, the MEF 3.0 format reference and
  runnable examples.

## Fixes

- Passing a float timestamp (for example `t + 10*1e6`) no longer crashes the
  Python interpreter.
- Truncated or malformed sessions raise an error naming the bad file instead of
  crashing.
- `write_int32` refuses float input and values outside the int32 range rather
  than silently altering them.

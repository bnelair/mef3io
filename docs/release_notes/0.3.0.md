# mef3io 0.3.0

*Released 2026-07-03*

The first release published to PyPI. It contains the full 0.2.0 feature set
(see [0.2.0](https://bnelair.github.io/mef3io/release_notes/0.2.0/)) plus fixes to the release builds.

## Highlights

- `pip install mef3io` wheels for CPython 3.10-3.14 on Linux (x86_64,
  aarch64), Windows (AMD64; ARM64 from Python 3.11) and macOS (Apple silicon
  and Intel).
- Prebuilt MATLAB MEX binaries attached to the GitHub release.

## Fixes

- macOS wheels now build against a supported minimum macOS version.
- The Linux MATLAB MEX binary no longer fails to load with a
  `GLIBCXX ... not found` error inside MATLAB; the C++ runtime is linked in.
- Free-threaded CPython 3.14 (`cp314t`) wheels are not built for now.

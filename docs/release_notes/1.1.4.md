# mef3io 1.1.4

*Released 2026-09-21*

## Highlights

- First MATLAB bundle and GitHub release since 1.1.2; includes everything from
  [1.1.3](1.1.3.md).

## Fixes

- **Windows: flushing to disk did not work.** With `durability="full"`, the
  first append to a session failed with "could not flush to disk". Elsewhere
  (the default `durability="fast"`, recovery backups) the flush failed silently,
  so those writes were never forced to disk. Linux and macOS were not affected.
- Windows: session paths containing non-ASCII characters can now be flushed and
  appended to.

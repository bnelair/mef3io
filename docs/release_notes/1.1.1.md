# mef3io 1.1.1

*Released 2026-07-07*

## Highlights

- Single-file session archives. `mef3io.archive_session("rec.mefd")` packs a
  session into one uncompressed `rec.mefd.tar`, which is easier to copy, share
  and archive than a directory tree. `extract_session` turns it back into a
  normal, writable session (byte-identical round trip).
- Read archives in place: pass the `.mefd.tar` path to any reader, in Python,
  MATLAB or C++. No extraction is needed, and windowed reads fetch only the
  bytes they need. Archives made with standard `tar` tools are accepted too.
- MATLAB: `mef3io.archiveSession` / `mef3io.extractSession`.

## Fixes

- Archives are read-only: writers refuse a `.tar` path, so an archive can never
  be overwritten or deleted by a write.

## Upgrading

- Session names are now enforced everywhere: a session directory must end in
  `.mefd` and an archive in `.mefd.tar`. Reading, writing, archiving or
  extracting any other name raises an error. Rename such sessions before
  upgrading.

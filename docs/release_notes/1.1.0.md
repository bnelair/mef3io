# mef3io 1.1.0

*Released 2026-07-04*

## Highlights

- Session metadata can now be set and read. `mef3io.Metadata`, `Subject` and
  `Acquisition` describe the subject (ID, names, recording location) and the
  recording (session and channel descriptions, filter settings, line frequency,
  and more).
  Pass them with `Writer(metadata=...)` or `Writer.set_metadata()`, and read
  them back from `Reader.metadata`. Fill in only the fields you have; the rest
  keep their defaults.
- Subject fields are protected by the level-2 password in encrypted sessions,
  as in the MEF 3.0 encryption model.
- The same in MATLAB (`mef3io.Writer(..., Metadata=struct(...))`,
  `Reader.metadata`) and in the legacy-style `MefWriter`.

See [Session metadata](../metadata.md).
